# トークン効率化ルール

全 AI エージェント共通。CLAUDE.md / GEMINI.md にも反映すること。

## 出力ルール

- 長文説明禁止
- 箇条書き優先
- 差分のみ説明（変更のない既存コードは `// ... existing code ...` で省略）
- 重複説明禁止
- 推測を避ける
- 不要な前置き・挨拶禁止
- context を読んでから回答

## コード提案時

- 変更箇所のみ出力。ファイル全体を再出力しない
- import 文は変更がある場合のみ記載
- 型定義は必要最小限

## レビュー時

- 問題のないコードにはコメントしない
- 指摘は「ファイル名:行番号 → 修正内容」の形式
- 褒め言葉・解説は省略

## context 注入時

- 1 context file = 300〜800 tokens
- 超えたら分割するか要約する
- Vault（memory）を丸ごと LLM に食わせない
